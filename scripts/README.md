# Scripts

Utility scripts for local development and CI. All scripts are cross-platform
where possible; PowerShell variants are provided for Windows.

| Script                 | Purpose                                                     |
| ---------------------- | ----------------------------------------------------------- |
| `setup.sh` / `setup.ps1` | Install all workspace dependencies and the Python env.    |
| `check.sh` / `check.ps1` | Run typecheck + lint + format check across the monorepo.  |

Run from the repository root.
